# Attribution for SymbolsNerdFontMono-Regular.ttf

The bundled `HerdrupSymbols-Regular.ttf` is a MODIFIED version of the upstream
`NerdFontsSymbolsOnly` artifact from Nerd Fonts v3.5.1
(`SymbolsNerdFontMono-Regular.ttf`, sha256
fe471e538392f51910faab985fa8e192a39dd3426125edd15b71b3680df0e749, retained at
`Tools/upstream/` so the modification can be re-derived and audited).

WHAT WAS CHANGED. The intent is a private-use-only character map and a rename;
the full measured difference against the upstream binary, since an earlier
version of this file claimed "and nothing else" and was refuted by parsing the
two fonts:

  * cmap reduced from 10629 to 10610 codepoints. 19 dropped: the 14 outside the
    private-use area (U+23FB-U+23FE, U+2630, U+2665, U+26A1, U+276C-U+2771,
    U+2B58) and 5 control codepoints (U+0000, U+0008, U+0009, U+000D, U+001D).
  * cmap subtables 5 -> 4; the (platform 1, encoding 0) format-0 Macintosh
    subtable is dropped.
  * glyph records 10627 -> 10611, i.e. 16 removed, not 19: some dropped
    codepoints shared a glyph.
  * tables GDEF and PfEd are dropped (fontTools cannot subset PfEd, an editor
    private table).
  * head.yMin -473 -> -472, hhea.minLeftSideBearing -123 -> -122 and
    hhea.xMaxExtent 2171 -> 2170, all because the same removed glyph carried
    those extremes.
  * head.flags bit 1 cleared (0b1011 -> 0b1001) and head.checkSumAdjustment
    0x74c7a366 -> 0x07ec140b.
  * hhea.numberOfHMetrics 4 -> 1 (hmtx trailing-width compression); all 10610
    surviving advance widths are unchanged.
  * OS/2.usFirstCharIndex 9211 (U+23FB) -> 57344 (U+E000),
    OS/2.ulUnicodeRange2 0x1200C0A0 -> 0x12000000, and OS/2.ulCodePageRange1
    bit 31 (Macintosh character set) cleared, consistent with dropping the Mac
    cmap subtable.
  * post drops the 14 removed glyph names.
  * 2833 per-glyph bounding boxes are recompiled on save by fontTools.
  * name table retitled to "Herdrup Symbols" / PostScript "HerdrupSymbols".

Everything after the first three entries is bookkeeping the subsetter and the
compiler regenerate, and none of it is legally substantive — but it is listed
because this paragraph twice claimed a narrower scope than the binary had.

NO GLYPH CONTOUR IS EDITED: surviving outlines are the upstream outlines.

Why: the terminal needs the symbols ahead of Apple Color Emoji, which still maps
the legacy SoftBank private-use block and would otherwise hide 170 of these
glyphs; but ahead of the system it also won those 14 non-private-use codepoints,
turning emoji-presentation characters such as U+26A1 into monochrome glyphs. No
cascade order satisfies both, so the coverage changed instead. The reduction is
reproducible and CI-enforced: see `Tools/subset-symbols-font.py`.

The OFL permits modification and restricts only RESERVED FONT NAMES; the rename
above keeps that condition met. No reserved name is used by this font: not
Pomicons, and not "Font Awesome" — Font Awesome's own LICENSE.txt grants its
SVG/JS icons under CC BY 4.0 and its FONT FILES under OFL 1.1 with that reserved
name, and although Nerd Fonts patches from the SVGs (which is why both upstream's
table and the one below say CC BY 4.0), the artifact shipped here is a desktop
font file, so the stricter reading is assumed and satisfied.

It is an AGGREGATE: the binary contains glyphs from fourteen icon sets, each
under its own terms. The Nerd Fonts root licence below covers the project's own
source and patched fonts, and defers the rest to an out-of-band audit URL —
which is not a notice, and not something a shipped app can rely on. The sets
actually inside this binary, from upstream's own
`patched-fonts/NerdFontsSymbolsOnly/README.md` at v3.5.1:

THE SHIPPED FONT IS MODIFIED — the measured scope is at the top of this file and
is the only description of it that should be trusted. Two earlier versions of
this paragraph were wrong in turn: first it claimed the artifact "ships
unmodified ... shipped whole rather than trimmed", true when written and left
standing once it stopped being true; then its replacement narrowed the claim to
"limited to the character map and name table with no outline altered", which
parsing the binary also refuted — GDEF and PfEd are dropped, head, hhea, OS/2
and post all move, and 2833 bounding boxes are recompiled.

What holds: no glyph CONTOUR is edited, and the OFL condition is met by the
RENAME rather than by being unmodified. The font is titled "Herdrup Symbols"
(PostScript "HerdrupSymbols") and is not distributed under any reserved name.

Font Logos is listed as "unlicensed" in upstream's table. That label is
misleading and worth recording: its repository (https://github.com/lukas-w/font-logos)
ships The Unlicense, a public-domain dedication, so redistribution IS granted.
A review flagged this as a blocker on the upstream wording; the upstream
repository is the authority and it grants the right.

MIT-licensed sets are covered by the MIT text below; copyright remains with each
upstream project listed above.
